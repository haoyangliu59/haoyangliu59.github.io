# haoyangliu59.github.io

Source of my personal website, https://haoyangliu59.github.io — a single page built with
[Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) starter.

Pushing to `main` builds the site with GitHub Actions and publishes it to the `gh-pages` branch.
To preview locally, run `bin/serve` and open http://localhost:4000.

Content lives in `_pages/about.md` (bio), `_news/` (news), `_bibliography/papers.bib` (publications),
`_data/projects.yml`, `_data/internships.yml` and `_data/socials.yml`.
